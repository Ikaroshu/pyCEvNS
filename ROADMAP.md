# Roadmap

Tracked in the GitHub project [pyCEvNS: Agentic CEvNS prototype](https://github.com/users/Ikaroshu/projects/18). The design spec is mirrored in [#5](https://github.com/Ikaroshu/pyCEvNS/issues/5).

## Milestones

- M1 [#12](https://github.com/Ikaroshu/pyCEvNS/issues/12) Repository repurposing and the legacy half of the golden regression.
- M2 [#13](https://github.com/Ikaroshu/pyCEvNS/issues/13) Operator basis, model card, plugins and the master cross section, with legacy equivalence tests.
- M3 [#14](https://github.com/Ikaroshu/pyCEvNS/issues/14) Experiment registry with COHERENT CsI 2017 and `predict`; completes the golden regression against the new package.
- M4 [#15](https://github.com/Ikaroshu/pyCEvNS/issues/15) Likelihood, Δ versus the Standard Model, Asimov and observed-data scans (`compare`, `scan`).
- M5a [#16](https://github.com/Ikaroshu/pyCEvNS/issues/16) Agent context pack and eval set.
- M5b [#17](https://github.com/Ikaroshu/pyCEvNS/issues/17) Agent backends (`claude -p`, `codex exec`), harness and `propose`.
- M6 [#18](https://github.com/Ikaroshu/pyCEvNS/issues/18) Streamlit page and packaging.
- M7 [#21](https://github.com/Ikaroshu/pyCEvNS/issues/21) Conversational agent rounds (`questions.json`, `propose --answer`, the page's question form) and parameter re-evaluation on the page.

## Deferred

- [#6](https://github.com/Ikaroshu/pyCEvNS/issues/6) CENNS-10 argon experiment.
- [#7](https://github.com/Ikaroshu/pyCEvNS/issues/7) Tensor, axial and pseudoscalar structures; the difficulties are recorded in [docs/deferred_structures.md](docs/deferred_structures.md).
- [#8](https://github.com/Ikaroshu/pyCEvNS/issues/8) Timing information in the likelihood.
- [#9](https://github.com/Ikaroshu/pyCEvNS/issues/9) Anti-coincidence counts as a second Poisson measurement.
- [#10](https://github.com/Ikaroshu/pyCEvNS/issues/10) API-based agent backend.
- [#11](https://github.com/Ikaroshu/pyCEvNS/issues/11) Autonomous proposal loop and global likelihood.
